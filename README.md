# pr-lifecycle-demo

This repository exists so we can do a live walk-through of a complete pull-request lifecycle on GitHub, ahead of the new-engineer onboarding session.

## What is here

- `README.md` — this file, which briefly describes the demo.
- `greeter.py` — a small Python script that prints a friendly greeting.

## Roadmap

A branch named `feature/greeting-tweak` changes the greeting text in `greeter.py` to something friendlier, it is then opened as a draft pull request into `main`, and the lifecycle is walked through together in the meeting: draft, change-set check, ready-for-review, and on to merge.
